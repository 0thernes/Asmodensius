# Asmodensius

[![license: MIT](https://img.shields.io/badge/license-MIT-5b9cf6)](LICENSE)
[![not evidence of consciousness](https://img.shields.io/badge/claims-not%20evidence%20of%20consciousness-f5b041)](docs/index.html)

Artificial creatures with pre-registered, controlled tests of consciousness-indicator properties.
**These tests are not evidence of consciousness.** There is no aggregate score. Each test is narrow, functional and seeded.
The creature is tokenless, promptless and LLM-free, and runs on Node/Bun only.

## Layout
- `creatures/001/organism/`: the Creature #1 organism (`organism.ts`) and its test batteries (`tests_v*.ts`).
  Runners: `run_v39.ts` (frozen line) and `run_v41.ts` (v4.1; refuses to run without explicit seeds).
- `creatures/001/preregistrations/`: every preregistration, frozen before its test seeds were run.
- `creatures/001/results/`: raw outputs and scorecards. `results/identity/` holds the identity-gate goldens.
- `creatures/001/specialists/`: the specialist-method folders (10 approaches, hybrids, integration checks) and `tools/`.
- `creatures/001/index.html`, `index.v3.html`, `src/`, `harness/`: the older v2/v3 browser creature and its harness
  (historical; not the organism above).
- `lab/`: the dome (neutral environment), instruments, conformance suite and viewer.
- `docs/` (generated by `python3 site/gen.py`), `benchmark/`, `roadmap/`, `archive/` (quarantined history),
  `imports/` (material copied in for review, not wired in).
- `SEEDS.md`: the seed ledger. Never tune on seeds 1000 and up.

## Quick start
```
bun install                 # typescript + @types/node for typecheck (bun 1.4.4)
npm run identity            # ID-gate: Combo A 540-543 bit-identical to the frozen output, smoke trajectory identical
npm run smoke               # 4-day organism smoke, seed 540 (node bundle)
npm run conformance         # lab conformance + originality
B=$(bash creatures/001/specialists/tools/build_bundle.sh HEAD)   # node bundle of run_v41.ts
MODE=dev ARM=comboA SEEDBASE=540 ORG_V6=1 M50J='{"v6P":0,"v6Ak":0,"scAIm":0.5,"scBM":1}' ORG_MIND=v40 node $B RPT2R
```
Run measured work through a **node** bundle. Running the organism `.ts` directly under bun is not reproducible: the same
seed can give different numbers depending on what else the process imported or ran first (audit F61).
