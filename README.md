Artificial creatures with pre-registered, controlled tests of consciousness-indicator properties.
**These tests are not evidence of consciousness.** There is no aggregate score. Each test is narrow, functional and seeded.

- `creatures/001/`: Creature #001
  - `index.html`: standalone build
  - `src/`
  - `harness/`
  - `preregistrations/`
  - `results/`
- `docs/`: the research site, generated by `python3 site/gen.py` from `results.json`
- `benchmark/`: the 150-project ALife capability matrix. Rubric-based and not run by us.
- `roadmap/`: 100 capabilities, each with a prior-art check and a measurable test

v1 has three ceiling-limited failures (activeInference, CQM-10, CQM-21). They are kept as FAIL, and the v2 re-tests are reported alongside them.

Credits: [Eshkol](https://github.com/tsotchke/eshkol) and [Moonlab](https://github.com/tsotchke/moonlab) by Tsotchke, which inspired this work and are planned integrations.
