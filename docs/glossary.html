Glossary

Cohen's dStandardized mean difference: (mean_full − mean_ctrl)/pooled SD.
Welch tt statistic without the equal-variance assumption.
Ablation controlSame system with the hypothesized mechanism removed.
Random controlMechanism replaced by a random process with matched statistics.
Ceiling-limited failureThe v1 test design left no headroom above the control (both at or near the maximum), so a pass was impossible however good the mechanism. The failure is kept as a FAIL.
Pre-registrationTest, metric, controls and thresholds committed to git before implementation.
Attention schema (AST)A model the system keeps of its own attention, used to control it (Graziano).
Global workspace (GWT)Limited-capacity stage whose contents are broadcast to many modules (Baars, Dehaene).
Higher-order (HOT)Representations of the system's own first-order states, e.g. metacognitive confidence.
IIT / phi proxyIntegrated-information-style measure. Here it is a tractable proxy, not exact Φ.
Active inferenceAction selection minimizing expected free energy (Friston).
Participation ratio(Σλ)²/Σλ² of the covariance eigenvalues: the effective number of dimensions.
Sobel detailMean luminance-gradient magnitude of a rendered frame.
RV32IM32-bit RISC-V base integer ISA plus the multiply extension, interpreted in JS.
SwiftShaderGoogle's CPU implementation of Vulkan/GL, used as the disclosed GPU substrate in headless runs.
Established / theorized / speculativeEvidence labels on the grounding pages: established means replicated empirical findings, theorized means published models without decisive evidence, speculative means no accepted evidence.
