Systems: the integrated organism (Round 13)

One deterministic, seedable TypeScript module (creatures/001/organism/organism.ts) couples a 1850-synapse LIF spiking CNS + ENS, seven neuromodulators, an exact kJ metabolic ledger, hormones, a circadian/two-process sleep system with NREM replay and REM recombination, a latent-curvature interoceptive loop, and a 3-qubit state-vector noise source. The node test suite and the browser creature run the same file. Organism parameters (seed 2000): 2,283. In the browser it is coupled both ways to the 100M procedural-weight GPU net and its 680,008 learned parameters (≈100.68M in total, counted honestly: the 100M weights are fixed hash functions, not trained).

Caveats

  • C5, C6 and C7 test couplings that are wired directly, so passing confirms the wiring works end to end; it is not a discovery.
  • C2 failed: sleep beats forced wake (d 1.98), but against "sleep with replay off" t = 2.63 < 2.75. C8b failed: a higher intelligence level does not measurably improve choice (d 0.22).
  • The quantum layer is a classical simulation of a 3-qubit state vector. C9 found no quantum advantage, as preregistered.
  • Ports from tsotchke (QGT definition, NIST RCT/APT health tests) are re-implementations of the definitions, not the original code.
