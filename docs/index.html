A browser creature with a real-time shader body, a recurrent controller and a test harness. All tests are pre-registered, controlled and seeded (1000–1015, n=16). The pass rule is Cohen's d ≥ 0.8 and Welch t ≥ 2.75 against every control.

Stated plainly: v1 has 3 failures (activeInference, 10, 21). activeInference and CQM-10 hit the ceiling: full and passive/random-switching controls both score 1.000. CQM-21 fails on differentiation: the uncoupled control is iid fair coins, the maximum-entropy source. A round-7 binary-counter mechanism that passed only by covering states more evenly than chance was reverted in round 8, because a deterministic state cycle is not genuine differentiation. CQM-21 stays FAIL until a real mechanism passes the frozen test. The failures stay recorded as FAIL under the v1 pre-registration, and their criteria are not changed. Pre-registration v2 added new non-ceiling tests for the same properties. There, 3/3 pass, and they are shown next to the v1 failures below. A v2 pass does not convert a v1 failure into a pass.
Not evidence of consciousness. There is no aggregate consciousness score. Each item is a narrow functional test of one indicator property, and passing it shows only that the mechanism beats its controls on that test.
