Tests and CI

Pre-registrations: creatures/001/preregistrations/ (v1, v2, v2.1, v2.2, v2.3, v2.4, v2.5, v2.5a). Each one was committed before its test code was written. CI (.github/workflows/harness.yml) type-checks the page with tsc, runs the full harness, and runs the cross-process SHA-256 reproducibility check.

Badges are wired to GitHub Actions and become live once the repository is published. It is not published yet.
